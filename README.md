# Academic Website

A clean, modern academic website for an Economics PhD candidate.

## Setup

1. Replace placeholder content in `index.html`:
   - `[Your Name]` - Your full name
   - `[Your Institution]` - Your university
   - Update bio text in the About section
   - Add your paper titles and abstracts in the Research section
   - Update contact information

2. Add your files:
   - Add your headshot to `images/headshot.jpg`
   - Add your CV to `files/cv.pdf`
   - Add your paper PDFs to `files/`

3. Deploy to GitHub Pages:
   - Create a repository named `yourusername.github.io`
   - Push these files to the repository
   - Your site will be live at `https://yourusername.github.io`

## File Structure

```
├── index.html      # Main page
├── css/
│   └── style.css   # Styling
├── js/
│   └── main.js     # Interactive features
├── images/         # Profile photo
└── files/          # CV and papers
```

## Features

- Responsive design (mobile-friendly)
- Expandable paper abstracts
- Clean, professional styling
- No external dependencies (except Google Fonts)
